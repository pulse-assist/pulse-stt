# Установка плагина «SpeechToText» (распознавание речи)

Инструкция для агента Пульса после `pulse plugins install …`. Пройди её целиком.

## 1. Проверь, что плагин запустился

```bash
pulse plugins list            # у stt — status: running
pulse stt models              # сервисы распознавания: что настроено (configured) и в каком порядке
```

Если status: error — `pulse plugins logs stt --lines 80`, расскажи владельцу, что в журнале, и остановись.
Нужен Пульс с контрактом плагинов 1.6 (распознавание речи, долгие команды).

## 2. Сервис распознавания — ключи задаёт владелец

Значений по умолчанию нет. Спроси владельца, какими сервисами он хочет пользоваться (можно несколько — первый
основной, остальные запасные), и есть ли у него ключи (для доверенных установок их выдаёт администратор Пульса):

- **OpenAI** — platform.openai.com → API keys; модель по умолчанию `gpt-4o-transcribe` (точнее), `whisper-1` —
  с точным временем фраз для субтитров.
- **Groq** — console.groq.com → API Keys; `whisper-large-v3-turbo`: быстро и дёшево.
- **Yandex SpeechKit** — Yandex Cloud, API-ключ сервисного аккаунта с ролью `ai.speechkit-stt.user`; хорош для
  русского, работает из России.
- **Свой сервер** — совместимый с OpenAI (`faster-whisper-server`, `speaches`, vLLM): адрес вида
  `http://хост:порт/v1` и имя модели.

Ключи — в Настройки → Плагины → SpeechToText или командами (ключ — через stdin, не `--value`; в ответах не повторяй):

```bash
printf '%s' "$KEY" | pulse plugins secret stt openai_api_key        # groq_api_key, yandex_api_key, custom_api_key
pulse plugins settings stt set order="groq, openai"                 # порядок: первый настроенный — основной
pulse plugins settings stt set language=ru vocabulary="Пульс, ИТМО" # язык и словарь имён — по желанию владельца
```

## 3. Проверь доступ к сервисам — обязательно

```bash
pulse stt check               # по шагам: ffmpeg, прокси, каждый настроенный сервис (ключ, сеть, модель)
```

То же — кнопка «Проверить подключение» в настройках плагина и на его странице. Не проходит сеть до сервиса
(OpenAI и Groq не работают из России, SpeechKit может не отвечать из-за рубежа) — нужен прокси. Спроси владельца,
есть ли у него прокси или сервер (описание может лежать в его карточках и файлах: `pulse cards list --q прокси`,
`pulse files find прокси`). Адрес прокси — секрет: `printf '%s' "$PROXY_URL" | pulse plugins secret stt proxy`
(`http://логин:пароль@хост:порт` или `socks5://…`). Повтори `pulse stt check`, пока все шаги не станут ok.
Нет ffmpeg — переустанови плагин (он ставит свой ffmpeg пакетом imageio-ffmpeg).

## 4. Закрепи страницу (если владелец хочет)

```bash
pulse plugins pin stt main
```

## 5. Проверь и расскажи владельцу

```bash
pulse stt check
pulse stt models
```

Что установлен «SpeechToText» (версия), какие сервисы настроены и какой основной. Где теперь работает голос:
голосовые и «кружочки» боту в Telegram — сразу ответ; кнопка микрофона в поле ввода чатов Пульса — сказанное сразу
уходит сообщением (браузер спросит доступ к микрофону, нужен HTTPS); записи встреч и видео — «расшифруй» в чате
(агенты знают команду `pulse stt transcribe`). На странице [Распознавание речи](/p/stt/main) — проба, история и
расход за месяц.
