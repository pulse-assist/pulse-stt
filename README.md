# SpeechToText для «Пульса»

Плагин распознавания речи: подключает модели к голосу «Пульса».

- **Telegram.** Голосовые, «кружочки» и аудио боту-пульту распознаются, и агент сразу отвечает на сказанное.
- **Чаты Пульса.** Кнопка микрофона в поле ввода: запись в браузере → текст → сразу сообщением.
- **Агенты.** `pulse stt transcribe --file … [--format text|md|srt|vtt|json] [--out …]` — записи встреч, лекции,
  видео любой длины, файлы из «Файлов», @yadisk, @gdrive и вложения чата. Скилл подсказывает агенту, как сделать
  из записи встречи протокол.
- **Страница** — модели и их порядок, «Попробовать» (микрофон или файл), история распознаваний, расход за месяц.

## Сервисы

| Сервис | Модели | Особенности |
|---|---|---|
| OpenAI | `gpt-4o-transcribe`, `gpt-4o-mini-transcribe`, `whisper-1` | точность; время фраз — у `whisper-1` |
| Groq | `whisper-large-v3-turbo`, `whisper-large-v3` | быстро и дёшево, время фраз |
| Yandex SpeechKit | `general` | русский, работает из России; части по 25 с |
| Свой сервер | любая (faster-whisper, speaches, vLLM, LocalAI) | совместимый с OpenAI `/audio/transcriptions` |

Порядок — настройка `order`: первый настроенный — основной, не ответил — пробуется следующий. Ключи — только в
настройках плагина (секреты); в коде и репозитории их нет.

## Как устроено

Ядро «Пульса» (контракт плагинов 1.6) не знает моделей: оно отдаёт записи плагину с правом `speech:provide`
(`POST /speech/transcribe`, `pulse_plugin.speech`). Плагин через ffmpeg (свой, из пакета `imageio-ffmpeg`) достаёт
звук, сжимает (моно 16 кГц), режет длинное по паузам, распознаёт части параллельно и склеивает. Сами записи не
хранятся; текст распознаваний — 30 дней (настройка `history_days`) для истории на странице. Прокси — настройка
`proxy` (для OpenAI, Groq и SpeechKit; свой сервер — напрямую).

## Разработка

```bash
pip install -r backend/requirements-dev.txt
pulse-plugin check
cd backend && python -m pytest          # сервисы подменены, сеть не нужна; ffmpeg — настоящий
```

Нужен Пульс с контрактом плагинов 1.6.
